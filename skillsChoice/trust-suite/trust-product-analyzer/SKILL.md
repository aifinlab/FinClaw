# 信托产品分析助手

## 数据获取

通过 AkShare 和用益信托网获取数据：
- **产品信息**: 产品名称、发行方、规模、期限、收益率
- **风险数据**: 信用评级、底层资产、担保措施
- **市场数据**: 同类产品收益率分布、发行趋势

## 分析工作流

### Step 1: 产品信息解析
- 抓取目标产品基本要素（规模、期限、预期收益、起投金额）
- 识别产品类型（集合信托/单一信托）和投向（固收/权益/混合）
- 验证数据完整性：确认核心字段无缺失

### Step 2: 风险评级
- 信用风险：融资主体评级、担保措施、偿债能力
- 市场风险：利率敏感度、底层资产波动性
- 流动性风险：期限、提前赎回条款、转让限制
- 综合评分（0-100分）→ 映射风险等级（R1-R5）

### Step 3: 收益测算与对比
- 计算内部收益率（IRR）和到期收益
- 与同期限、同类型产品横向对比
- 费后实际收益率 = 预期收益 - 管理费 - 托管费

### Step 4: 合规检查
- 合格投资者门槛验证
- 投资者适当性匹配
- 信息披露完整性

### Step 5: 输出报告

## 输出格式

### formal 风格（尽调报告）
```
# [产品名称] 尽调分析报告

## 一、产品概况
| 要素 | 内容 |
|------|------|

## 二、风险评估
| 维度 | 评分 | 等级 |
|------|------|------|

## 三、收益测算
[IRR、费后收益对比]

## 四、合规意见
[适当性匹配结论]
```

### brief 风格（快速筛选）
```
## [产品名称] 速评
- 规模 X 亿，期限 X 月，预期 X.X%
- 风险评分 72/100 (R3)，底层资产 AA+
- 同类排名前 30%，费后收益 X.X%
- 合规：通过 ✓
```
