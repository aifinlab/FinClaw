# 信托风险管理助手

## 数据获取

所需输入数据：
- **资产组合**: 持仓明细（资产类型、规模、信用评级、到期日）
- **市场数据**: 利率曲线、信用利差、股票/商品价格
- **阈值配置**: 风险限额（集中度 <15%、久期 <3年、杠杆率等）

## 分析工作流

### Step 1: 信用风险评估
- 汇总各资产信用评级分布（AAA/AA+/AA/AA-及以下）
- 计算单一主体/行业/区域集中度
- 预警条件：单一主体敞口 >15% 或评级低于 AA-

### Step 2: 市场风险量化
- 计算组合久期和凸性
- VaR (95%, 1日) 和 CVaR 计算
- 利率敏感性：±100bp 对组合净值的影响

### Step 3: 流动性风险分析
- 期限错配度量：负债到期 vs 资产到期缺口
- 流动性比率 = 流动资产 / 总资产（阈值 >1.0）
- 赎回压力测试：极端赎回情景下的变现能力

### Step 4: 压力测试
- 场景设置：利率上升100bp、股市下跌20%、信用利差扩大200bp
- 计算各场景下组合价值变动
- 联合压力测试：多因子同时冲击

### Step 5: 风险预警与处置建议
- 汇总黄色/红色预警指标
- 提供处置建议（减仓、对冲、增加担保）

## 输出格式

### formal 风格（风险报告）
```
# [组合名称] 风险评估报告

## 一、风险概览
| 指标 | 数值 | 阈值 | 状态 |
|------|------|------|------|
| VaR (95%) | X万 | <5%总资产 | ✓/⚠ |
| 集中度 | X% | <15% | ✓/⚠ |

## 二、信用风险
[评级分布、集中度]

## 三、市场风险
[久期、利率敏感性]

## 四、压力测试
[场景分析结果]

## 五、预警与建议
[预警清单及处置建议]
```

### brief 风格（快速扫描）
```
## 风险速览
- 综合风险评分 65/100，中等
- VaR(95%) 125万，占总资产 3.2% ✓
- ⚠ 单一主体集中度 18%（超限15%）
- 建议：减持最大敞口主体至限额内
```
