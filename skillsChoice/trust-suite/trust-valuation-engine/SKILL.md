# 信托资产估值助手

## 数据获取

估值所需数据：
- **债权资产**: 合同现金流、还款计划、信用评级、市场利率曲线
- **股权资产**: 财务报表、可比公司交易数据、行业估值倍数
- **组合数据**: 持仓明细、成本价、公允价值、计提拨备记录

## 估值工作流

### Step 1: 资产分类与方法选择
- 非标债权 → 现金流折现法（DCF）
- 未上市股权 → 市场法（可比公司/可比交易）或收益法
- 上市证券 → 市价法（收盘价/VWAP）
- 混合资产 → 多方法交叉验证

### Step 2: 非标债权估值
- 映射合同现金流（本金、利息、费用）
- 选择折现率：无风险利率 + 信用利差 + 流动性溢价
- DCF 计算：PV = Σ CFₜ / (1 + r)ᵗ
- 信用调整：根据违约概率（PD）和违约损失率（LGD）调整

### Step 3: 股权估值
- 市场法：选取可比公司，计算 PE/PB/EV-EBITDA 倍数，调整流动性折扣（20%-30%）
- 收益法：预测未来自由现金流，选择 WACC 折现
- 资产基础法：调整后净资产 = 总资产公允价值 - 总负债公允价值
- 多方法取加权平均或中位数

### Step 4: 净值计算
- 单位净值 = (总资产公允价值 - 负债 - 费用计提) / 总份额
- 与上期比较，计算净值变动率
- 验证：净值变动率 >5% 需复核估值假设

### Step 5: 减值测试
- 逐资产比较账面价值与可回收金额
- 可回收金额 = max(公允价值 - 处置费用, 使用价值)
- 需计提减值 = 账面价值 - 可回收金额（当为正时）
- 汇总减值计提对组合净值的影响

### Step 6: 输出估值报告

## 输出格式

### formal 风格（估值报告）
```
# 信托资产估值报告

## 一、估值概览
| 资产类别 | 账面价值 | 公允价值 | 差异 |
|----------|----------|----------|------|

## 二、非标债权估值
[折现率、DCF结果、信用调整]

## 三、股权估值
[可比公司、倍数、流动性折扣]

## 四、净值计算
| 日期 | 单位净值 | 变动率 |
|------|----------|--------|

## 五、减值测试
[减值计提明细]
```

### brief 风格（估值速览）
```
## 估值速览
- 组合总公允价值 XX 亿，较账面 +/-X%
- 非标债权折现值 XX 亿（折现率 X.X%）
- 股权估值 XX 亿（PE 法，流动性折扣 25%）
- 单位净值 1.0XX，本期 +X.X%
- 需计提减值 XX 万（1笔非标债权）
```
